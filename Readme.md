# Laundry Wallah / Laundry Mart

This project is a basic HTML webpage for Laundry Wallah / Laundry Mart.

## Features

- Welcome heading and introduction
- Laundry-related image
- List of laundry services
- Price list using an HTML table
- Book Now form with Name, Email, and Phone fields
- Submit button
- Contact information in the footer

## Technologies Used

- HTML5

## How to Run

Open the `index.html` file in any web browser to view the webpage.
